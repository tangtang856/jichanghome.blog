Windows系统配置Clash Verge Rev节点完整教程

更新日期：2026年3月 • 阅读时长：约 6 分钟 • 实操难度：入门简易

一、为什么优先推荐 Clash Verge Rev？

自原版 Clash for Windows (CFW) 停止维护后，Clash Verge Rev 凭借基于 Tauri 框架开发的现代化轻量界面、原生集成 Mihomo (Clash.Meta) 开源核心以及对 Windows 10/11 的极佳兼容性，已成为目前 Windows 平台体验最优秀的客户端首选。

二、准备工作

  • 一台运行 Windows 10 或 Windows 11 的电脑。
  • 有效可用的机场订阅链接（如 飞鸟云 或 泡泡狗 提供的 Clash 格式订阅）。
  • 从官方 GitHub Releases 或机场后台下载最新版 Clash.Verge_x64-setup.exe 安装包。

三、详细配置实操步骤

第 1 步：安装客户端

双击安装程序，按提示点击“下一步”完成安装。初次运行时，Windows Defender 若弹出网络防火墙提示，请勾选“专用网络”和“公用网络”并点击“允许访问”。

第 2 步：导入订阅链接

  1. 打开 Clash Verge Rev，在左侧导航栏点击 订阅 (Profiles)。
  2. 在顶部输入框中粘贴您的机场订阅链接（URL），右侧名称可自定义填写（如“我的主力机场”）。
  3. 点击 导入 (Import) 按钮。客户端会自动拉取远程配置，成功后列表中会显示节点数量与更新时间。
  4. 右键刚导入的配置卡片，选择 使用 (Use)，卡片边框变蓝即表示激活。

第 3 步：选择节点与开启系统代理

  1. 点击左侧导航栏的 代理 (Proxy)，将代理模式切换为 规则 (Rule)（推荐，国内直连国外代理）。
  2. 展开 节点选择 (Proxy) 组，点击延迟测速按钮（闪电图标），选择一个绿色延迟较低的节点（如香港、日本或新加坡）。
  3. 点击左侧导航栏的 设置 (Settings)，打开 系统代理 (System Proxy) 开关。
  4. 此时打开浏览器访问 google.com 即可验证是否成功翻墙。

四、高阶玩法：开启 TUN 模式接管全系统流量

部分应用程序（如 Windows 终端 CMD/PowerShell、Git 命令行或部分游戏客户端）不会主动读取系统代理。此时开启 TUN 模式 可以创建虚拟网卡接管系统所有流量：

  • 在设置中找到 TUN 模式 (Tun Mode) 并点击开启。
  • 首次开启时系统会请求管理员权限安装虚拟网卡驱动（Wintun），点击“是”即可。

五、常见问题排查

Q：开启系统代理后国内网站打不开？
A：检查代理模式是否误选为“全局 (Global)”，请切换回“规则 (Rule)”模式。

Q：提示 7890 端口被占用？
A：在设置中将“混合端口 (Mixed Port)”修改为其他未被占用的端口号（如 7895），然后重启软件。
