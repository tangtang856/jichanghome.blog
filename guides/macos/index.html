macOS苹果电脑节点客户端配置与TUN模式指南

更新日期：2026年3月 • 阅读时长：约 6 分钟 • 实操难度：入门简易

一、macOS 客户端版本选择

目前在 macOS 上体验最丝滑的客户端依然是 Clash Verge Rev (Mac版)。它基于 Rust/Tauri 构建，内存占用比以往基于 Electron 的旧版客户端大幅降低，且原生支持 Apple Silicon (M1/M2/M3/M4) 架构芯片。

二、下载与安装说明

  1. 根据您的 Mac 处理器芯片选择对应的安装包：
    • Apple Silicon (M系列芯片)：下载 Clash.Verge_aarch64.dmg。
    • Intel 处理器芯片：下载 Clash.Verge_x64.dmg。
  2. 双击打开 DMG 文件，将 Clash Verge 图标拖入 Applications (应用程序) 文件夹。

解决“已损坏，无法打开”安全拦截

如果由于 macOS Gatekeeper 安全机制提示“无法打开，因为无法验证开发者”，请打开 Mac 的 系统设置 → 隐私与安全性，在底部找到被拦截的 Clash Verge，点击 仍要打开 即可。

三、导入订阅与开启代理

  1. 打开应用，进入 订阅 (Profiles) 页面。
  2. 在顶部输入框粘贴机场订阅链接，点击 导入 (Import)。
  3. 右键导入成功的配置，点击 使用 (Use)。
  4. 进入 代理 (Proxy) 页面，选择喜欢的节点（如香港或日本）。
  5. 进入 设置 (Settings) 页面，勾选 系统代理 (System Proxy)。

四、开启 TUN 虚拟网卡模式（终端加速利器）

经常使用终端写代码、执行 git clone 或 brew install 的开发者，强烈建议开启 TUN 模式：

  • 在设置中开启 TUN 模式。
  • 系统会弹出管理员密码授权窗口，输入开机密码以允许创建虚拟网络接口。
  • 开启后，终端命令无需额外设置 export http_proxy 环境变量，即可实现自动走高速代理。
