隐私权保护政策

最后更新：2026年1月 • 恪守原则：数据最小化与不采集个人敏感数据

机场之家（jichanghome.blog，以下简称“本站”）深知个人隐私的重要性。本隐私政策旨在向您说明本站在您浏览页面时如何对待访问信息：

一、我们不收集哪些信息？

  • 本站不强制用户注册或登录，因此不收集任何用户的真实姓名、手机号、身份证件号码或银行卡密码。
  • 本站为纯静态 HTML 资讯站，不设任何收集个人隐私的跟踪器或侵入式脚本。

二、服务器访问日志

与绝大多数现代网站一样，当您访问本站时，托管服务商（如 Cloudflare / GitHub）的基础设施可能会自动记录标准 Web 访问日志（包含匿名化的 IP 地址、浏览器类型、请求的 URL、访问时间戳等）。此类日志仅用于防御恶意 DDOS 攻击、排查网络连接故障及统计基础页面浏览量，绝不与任何个人身份进行关联匹配。

三、Cookie 的使用

本站自身不设置任何追踪用户个人身份的持久性 Cookie。某些第三方托管节点（如 Cloudflare 安全防护模块）可能会放置必要的安全识别 Cookie，以区分正常访客与恶意自动化爬虫机器人。

四、外部链接免责

本站包含前往第三方网站（包括机场官方网站、GitHub 开源仓库等）的超链接。当您点击跳转到外部第三方网站时，请注意第三方网站拥有其独立的隐私权政策，本站对第三方的行为与数据处理不承担任何法律责任。
