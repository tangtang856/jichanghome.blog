什么是Clash订阅链接与分流规则？

词条分类：网络技术名词 • 核验状态：技术组审核通过 • 更新日期：2026年3月

一、什么是 Clash？

Clash 是一款基于 Go 语言开发的跨平台开源代理核心客户端。它以灵活强大的规则分流（Rule-based Routing）著称，一改传统代理软件要么全部走代理、要么全部不走代理的僵硬体验。

二、什么是订阅链接？

订阅链接本质上是一个远程网络 URL 地址。当你在客户端（如 Clash Verge Rev、Clash Meta for Android）中导入该链接时，客户端会通过 HTTPS 请求向机场服务器拉取一段格式化的 YAML 配置文件。配置文件内包含：

  1. 服务器节点列表：包括每个节点的 IP/域名、端口、加密算法、密码或 UUID 密钥。
  2. 策略组（Proxy Groups）：如“节点选择”、“自动选择（自动测速选取延迟最低）”、“流媒体分流”等。
  3. 分流规则集（Rules）：成千上万条域名与 IP 匹配规则。

三、智能分流的核心机制：为什么访问百度不耗费流量？

当你的浏览器发起一个网页请求时，Clash 内核会自上而下匹配规则集：

  • 如果访问 baidu.com、taobao.com 或中国大陆 IP 段，命中 GEOIP,CN,DIRECT 规则，流量直接通过本地宽带直连访问，完全不消耗机场套餐流量。
  • 如果访问 google.com 或 youtube.com，命中 MATCH,PROXY 规则，流量自动封装加密并送往你选择的海外高速节点。
