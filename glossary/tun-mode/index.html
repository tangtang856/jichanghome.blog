什么是TUN虚拟网卡模式？

词条分类：网络技术名词 • 核验状态：技术组审核通过 • 更新日期：2026年3月

一、系统代理 (System Proxy) 的局限性

常规情况下，我们开启客户端时启用的是“系统代理（System Proxy）”。系统代理只是在操作系统中注册了一个本地 HTTP/SOCKS5 端口（如 127.0.0.1:7890）。

致命缺陷：只有主动读取系统代理设置的软件（如 Chrome 浏览器、Edge 浏览器）才会把流量交给代理客户端；而 Windows 命令行 CMD、PowerShell、Git Bash、各类游戏客户端以及防代理应用会直接绕过系统代理，导致命令行 git clone 频繁超时或报错。

二、TUN 模式的工作原理

TUN 是操作系统内核层级提供的一种虚拟点对点网络设备（Virtual Network Interface）。开启 TUN 模式后：

  • 客户端会在你的电脑或手机系统中虚拟出一张“虚拟网卡（Wintun / utun）”。
  • 客户端将该虚拟网卡设置为全系统的默认网关路由。
  • 从这一刻起，本机任何软件发出的所有三层（IP层）数据包，无论是 TCP、UDP 还是 ICMP（Ping），都会被无条件截获并送入代理核心进行规则分流，真正实现全系统 100% 流量无缝接管。
