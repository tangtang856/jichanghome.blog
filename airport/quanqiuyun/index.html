四、协议支持与各平台客户端兼容性

全球云 全面兼容目前主流的现代抗审查协议，支持 Shadowsocks、Trojan 等。

全平台第三方客户端均可无缝导入与托管：

  • Windows 桌面端：推荐使用 Clash Verge Rev 或 Sing-box 图形客户端，支持智能系统代理分流与 TUN 虚拟网卡模式。
  • macOS 苹果电脑：推荐使用 Clash Verge Rev 或 Surge 5，支持网关接管与沉浸式快捷菜单。
  • Android 安卓端：推荐使用 Clash Meta for Android 或 v2rayNG，支持按应用分流。
  • iOS 苹果手机：推荐使用 Shadowrocket（小火箭）、Stash 或 Loon，扫码或一键导入订阅即可使用。
